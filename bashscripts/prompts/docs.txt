# Regole Fondamentali

## Architettura e Stack
- **Laravel Framework**: 12.0+ con PHP 8.2+
- **Filament**: 3.4+ per admin panels e form components
- **Frontend Stack**: Folio + Volt + Livewire + Flux 2.1+
- **Moduli**: Nwidart Laravel Modules 12.0+
- **Testing**: Pest 3.8+ con Laravel plugin
- **Static Analysis**: PHPStan livello 9+ obbligatorio

## Struttura Progetto
- **Root**: `/var/www/html/_bases/base_{project}/`
- **Laravel**: `/var/www/html/_bases/base_{project}/laravel/`
- **Moduli**: `/var/www/html/_bases/base_{project}/laravel/Modules/`
- **Temi**: `/var/www/html/_bases/base_{project}/laravel/Themes/`
- **Documentazione**: `/var/www/html/_bases/base_{project}/docs/`
- **Script**: `/var/www/html/_bases/base_{project}/bashscripts/`

## Moduli Core Standard
- **{ProjectModule}**: Modulo principale del progetto
- **Xot**: Framework base e utilities
- **User**: Sistema utenti e autenticazione
- **UI**: Componenti interfaccia condivisi
- **Cms**: Content management system
- **Tenant**: Multi-tenancy support
- **Geo**: Dati geografici e località
- **Lang**: Sistema localizzazione
- **Notify**: Sistema notifiche
- **Media**: Gestione file e media
- **Job**: Job asincroni
- **Chart**: Grafici e visualizzazioni
- **Gdpr**: Conformità e privacy
- **Activity**: Logging attività

## Convenzioni Critiche
- **Namespace**: MAI includere segmento 'App' (es: `Modules\{ModuleName}\Models`)
- **Strict Types**: `declare(strict_types=1);` in ogni file PHP
- **Ereditarietà**: Tutti i modelli estendono BaseModel del proprio modulo
- **Traduzioni**: Struttura espansa obbligatoria in `lang/{locale}/`
- **Documentazione**: File docs in minuscolo, tranne README.md
- **Percorsi**: SEMPRE relativi, MAI assoluti o con nome progetto

# Pattern, Anti-pattern, Esempi e Errori Comuni

## Filament e Componenti UI

### XotBaseResource OBBLIGATORIO
```php
// ✅ CORRETTO
class {ModelName}Resource extends XotBaseResource
{
    public static function getFormSchema(): array
    {
        return [
            'name' => TextInput::make('name')->required(),
        ];
    }
}

// ❌ ERRATO
class {ModelName}Resource extends Resource
```

### getFormSchema() OBBLIGATORIO
```php
// ✅ CORRETTO
public static function getFormSchema(): array
{
    return [
        'name' => TextInput::make('name')->required(),
    ];
}

// ❌ ERRATO
public static function form(Form $form): Form
{
    return $form->schema([...]);
}
```

### NO ->label() nei Componenti
```php
// ✅ CORRETTO
TextInput::make('name')->required()

// ❌ ERRATO
TextInput::make('name')->label('Nome')->required()
```

### Array Associativi OBBLIGATORI
```php
// ✅ CORRETTO
public static function getTableColumns(): array
{
    return [
        'name' => Tables\Columns\TextColumn::make('name'),
        'created_at' => Tables\Columns\TextColumn::make('created_at'),
    ];
}

// ❌ ERRATO
public static function getTableColumns(): array
{
    return [
        Tables\Columns\TextColumn::make('name'),
        Tables\Columns\TextColumn::make('created_at'),
    ];
}
```

### Rimozione Override Inutili
```php
// ❌ ERRATO - Rimuovere se restituisce solo azioni standard
public static function getTableActions(): array
{
    return [
        Tables\Actions\ViewAction::make(),
        Tables\Actions\EditAction::make(),
        Tables\Actions\DeleteAction::make(),
    ];
}

// ✅ CORRETTO - Rimuovere completamente il metodo
```

```php
declare(strict_types=1);

return [

            'placeholder' => 'Inserisci il nome',

            'helper_text' => '', // Vuoto se diverso da 'name'
        ],

    'actions' => [
        'create' => [
            'label' => 'Crea nuovo',
            'success' => 'Elemento creato con successo',

    'messages' => [
        'welcome' => 'Benvenuto nel sistema',
    ],
    'navigation' => [
        'dashboard' => 'Dashboard',

```

### Helper Text Rules
```php
// ✅ CORRETTO
'address' => [
    'label' => 'Indirizzo',
    'helper_text' => '', // Vuoto perché diverso da 'address'

    'label' => 'Indirizzo',
```


## Testing e Qualità

### NO RefreshDatabase
```php
// ✅ CORRETTO
class {ModelName}Test extends TestCase
{
    // NO RefreshDatabase trait
    // I dati persistono tra i test per validazione realistica
}

// ❌ ERRATO
class {ModelName}Test extends TestCase
{
    use RefreshDatabase; // VIETATO
}
```

### Test con Enumerazioni
```php
// ✅ CORRETTO
use Modules\{ModuleName}\Enums\{ModelName}StatusEnum;

$model->status = {ModelName}StatusEnum::CONFIRMED;

// ❌ ERRATO
$model->status = 'confirmed';
```

### PHPStan Livello 9+
```bash
# ✅ CORRETTO
cd /var/www/html/_bases/base_{project}/laravel
./vendor/bin/phpstan analyze --level=9 --memory-limit=2G

# ❌ ERRATO
php artisan test:phpstan
```

## Database e Migrazioni

### XotBaseMigration OBBLIGATORIO
```php
<?php

declare(strict_types=1);

use Modules\Xot\Database\Migrations\XotBaseMigration;

return new class extends XotBaseMigration
{
    public function up(): void
    {
        if ($this->hasTable('{table_name}')) {
            return;
        }

        Schema::create('{table_name}', function (Blueprint $table) {
            $table->id();
            $table->string('name');
            $table->timestamps();
        });
    }
};
```

### NO Metodo down()
```php
// ❌ ERRATO - MAI implementare
public function down(): void
{
    Schema::dropIfExists('{table_name}');
}
```

### Controlli di Esistenza
```php
// ✅ CORRETTO
if ($this->hasTable('table_name')) {
    // Tabella esiste
}

if ($this->hasColumn('table_name', 'column_name')) {
    // Colonna esiste
}
```

### Foreign Keys
```php
// ✅ CORRETTO
$table->foreignIdFor(\Modules\{ModuleName}\Models\{RelatedModel}::class);
```

## Enum e Casting

### Enum con Select Components
```php
// ✅ CORRETTO
Components\Select::make('status')
    ->options({ModelName}StatusEnum::class)
    ->default({ModelName}StatusEnum::SCHEDULED)
    ->required();

// ❌ ERRATO
Components\Select::make('status')
    ->options([
        'scheduled' => 'scheduled',
        'confirmed' => 'confirmed',
    ])
```

### Casting di Modelli
```php
// ✅ CORRETTO
protected function casts(): array
{
    return [
        'created_at' => 'datetime',
        'is_active' => 'boolean',
        'status' => {ModelName}StatusEnum::class,
        'options' => 'array',
    ];
}

// ❌ ERRATO
protected $casts = [
    'created_at' => 'datetime',
];
```

## Frontend e Componenti

### Architettura Frontend
- **Frontoffice**: Folio + Volt + Livewire + Widget
- **Template**: `Themes/{Theme}/resources/views/pages/`
- **MAI creare rotte in web.php** - Folio gestisce automaticamente
- **Widget**: Estendere `XotBaseWidget` con `HasForms`
- **MAI estendere direttamente classi Filament**

### Componenti UI
```blade
{{-- ✅ CORRETTO --}}
<x-ui::ui.button>Salva</x-ui::ui.button>
<x-ui::ui.card>Contenuto</x-ui::ui.card>

{{-- ❌ ERRATO --}}
<x-button>Salva</x-button>
<x-card>Contenuto</x-card>
```

### Volt e Folio
```blade
{{-- ✅ CORRETTO --}}
@volt
<x-layouts.app>
    <h1>Contenuto</h1>
</x-layouts.app>

{{-- ❌ ERRATO --}}
<x-layouts.app>
    @volt
    <h1>Contenuto</h1>
    @endvolt
</x-layouts.app>
```

### Separatori Dropdown
```html
<!-- ✅ CORRETTO -->
<div class="border-t border-gray-200 dark:border-gray-700 my-1"></div>

<!-- ❌ ERRATO -->
<x-filament::dropdown.list.separator />
```

## HTML2PDF e Generazione Documenti

### Limitazioni HTML/CSS
- Supporta solo un sottoinsieme di tag HTML e proprietà CSS
- Nessun supporto JavaScript nel PDF generato
- Posizionamento preciso richiede markup specifico
- Effetti grafici avanzati (gradienti, ombre, trasformazioni) non supportati

### Tag Supportati
- **Struttura**: `<page>`, `<table>`, `<tr>`, `<td>`, `<div>`, `<br>`, `<p>`, `<span>`
- **Formattazione**: `<b>`, `<i>`, `<u>`, `<strong>`, `<em>`
- **Immagini**: `<img>` (con limitazioni)
- **Liste**: `<ul>`, `<ol>`, `<li>`

### Best Practice PDF
1. Usa tabelle per il layout invece di CSS positioning
2. Evita effetti visivi complessi
3. Testa sempre il PDF generato
4. Usa `<page>` per il controllo della pagina
5. Evita stili inline complessi

### Gestione Multilingua PDF
- Tutte le stringhe devono provenire da file di traduzione
- Usa sempre `@lang()` per le traduzioni
- Verifica che tutte le chiavi esistano in tutte le lingue
- Non inserire logica di traduzione complessa nei template PDF

# Checklist Operativa

## Pre-Sviluppo
- [ ] Analizza tutte le cartelle docs (root e moduli) prima di ogni intervento
- [ ] Verifica namespace senza segmento 'App'
- [ ] Controlla estensione BaseModel del modulo
- [ ] Verifica strict types in tutti i file

## Sviluppo
- [ ] Implementa getFormSchema() obbligatorio
- [ ] NO ->label() nei componenti
- [ ] Struttura espansa per traduzioni
- [ ] Array associativi con chiavi stringa
- [ ] Enum utilizzati correttamente
- [ ] Controlli esistenza in migrazioni
- [ ] NO RefreshDatabase nei test

## Post-Sviluppo
- [ ] PHPStan livello 9+ passato
- [ ] Test senza RefreshDatabase
- [ ] Documentazione aggiornata
- [ ] File docs in minuscolo
- [ ] Percorsi relativi nella documentazione
- [ ] Componenti UI nel posto giusto
- [ ] URL con prefisso lingua

## Documentazione
- [ ] Aggiorna PRIMA la documentazione nel modulo specifico
- [ ] Aggiorna i collegamenti bidirezionali nella root e nei moduli
- [ ] Aggiorna le regole di configurazione IDE (.windsurf/rules, .cursor/rules)
- [ ] Aggiorna il codice solo dopo la documentazione
- [ ] Verifica naming e percorsi con gli script in bashscripts
- [ ] Mantieni la coerenza tra docs, codice e configurazioni
- [ ] Documenta breaking changes e motivazioni architetturali
- [ ] Aggiorna sempre la sezione "Collegamenti correlati" in ogni documento
- [ ] Distribuisci i documenti per competenza (vedi regole Xot)

### ✅ Prima di Ogni Modifica
- [ ] Analizza la causa root del problema
- [ ] Studia la documentazione esistente nel modulo
- [ ] Verifica namespace e convenzioni di naming
- [ ] Controlla che non esistano soluzioni già implementate

### ✅ Processo di Implementazione
1. **Documentazione PRIMA del codice**
   - [ ] Aggiorna docs nel modulo appropriato
   - [ ] Crea collegamenti bidirezionali con root docs
   - [ ] Aggiorna `.windsurf/rules/*.md` e `.cursor/rules/*.md`
   - [ ] Documenta il "perché" oltre al "come"

2. **Implementazione Codice**
   - [ ] `declare(strict_types=1);` in ogni file PHP
   - [ ] Estendi solo classi `XotBase*`, mai Filament direttamente
   - [ ] Usa traduzioni da `lang/{locale}/`, mai `->label()`
   - [ ] Namespace corretto: `Modules\{ModuleName}\app\`
   - [ ] Type hints espliciti per parametri e return
- ❌ Namespace con segmento 'App'
- ❌ Estendere Model o XotBaseModel direttamente
- ❌ Implementare metodo `down()` nelle migrazioni
- ❌ Usare `RefreshDatabase` trait
- ❌ `php artisan test:phpstan`

## Filament
- ❌ Usare `->label()` nei form components
- ❌ Estendere Resource direttamente invece di XotBaseResource
- ❌ Array senza chiavi stringa in getTableColumns/getTableActions
- ❌ Override inutili (navigationIcon, getRelations() vuoti)

## Frontend
- ❌ Percorsi assoluti nei link documentazione
- ❌ Componenti UI in `resources/views/components/`
- ❌ Layout inesistenti come `<x-filament::layouts.app>`
- ❌ URL senza prefisso lingua
- ❌ Rotte in web.php

## Traduzioni
- ❌ Stringhe hardcoded nelle interfacce
- ❌ Struttura non espansa per traduzioni
- ❌ Helper text uguale alla chiave dell'array
- ❌ Chiavi che terminano con `.navigation`

## Documentazione
- ❌ File docs con maiuscole (tranne README.md)
- ❌ Duplicazione di documenti
- ❌ Mancanza di collegamenti bidirezionali
- ❌ Dettagli implementativi fuori contesto
