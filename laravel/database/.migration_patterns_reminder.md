# 📋 MIGRATION PATTERNS - UUID PROJECT

## 🎯 PROJECT-SPECIFIC MIGRATION RULES

### 🚨 CRITICAL REMINDER
This project uses **UUID primary keys**, not auto-increment IDs. All foreign keys must be `string` type.

### ✅ CORRECT COLUMN DEFINITIONS

**Foreign Keys (Relationships):**
```php
// One-to-Many relationship
$table->string('user_id'); // NOT unsignedBigInteger
$table->foreign('user_id')->references('id')->on('users');

// Nullable relationship  
$table->string('causer_id')->nullable();
$table->foreign('causer_id')->references('id')->on('users');
```

**Polymorphic Relationships:**
```php
// Subject morph (e.g., activity log)
$table->string('subject_id')->nullable(); // UUID string
$table->string('subject_type')->nullable();

// Causer morph  
$table->string('causer_id')->nullable(); // UUID string
$table->string('causer_type')->nullable();
```

**Changing Existing Columns:**
```php
// Making causer nullable (correct for UUID)
Schema::table('activity_log', function (Blueprint $table) {
    $table->string('causer_id')->nullable()->change();
    $table->string('causer_type')->nullable()->change();
});
```

### ❌ WRONG PATTERNS (AVOID THESE)

```php
// These will break UUID relationships!
$table->unsignedBigInteger('user_id'); // WRONG!
$table->unsignedBigInteger('causer_id')->nullable(); // WRONG!

// Wrong morph columns
$table->unsignedBigInteger('subject_id')->nullable(); // WRONG!
$table->unsignedBigInteger('causer_id')->nullable(); // WRONG!
```

### 🔄 MIGRATION TEMPLATES

**Create Table with UUID Relationships:**
```php
public function up(): void
{
    Schema::create('activity_log', function (Blueprint $table) {
        $table->uuid('id')->primary();
        $table->string('log_name')->nullable();
        $table->text('description');
        
        // Polymorphic relationships (UUID)
        $table->string('subject_id')->nullable();
        $table->string('subject_type')->nullable();
        $table->string('causer_id')->nullable(); // ✅ UUID string
        $table->string('causer_type')->nullable();
        
        $table->json('properties')->nullable();
        $table->timestamps();
        
        $table->index('log_name');
    });
}
```

**Modify Existing Table:**
```php
public function up(): void
{
    Schema::table('activity_log', function (Blueprint $table) {

```
