# Errore: Metodo `icon()` su FileUpload di Filament (modulo Patient)

## Nota
Il metodo `icon()` **non va mai usato** sul componente `FileUpload` di Filament perché non esiste e genera errore fatale. Se si necessita di un'icona, bisogna implementare una soluzione custom (es. slot Blade, CSS).
